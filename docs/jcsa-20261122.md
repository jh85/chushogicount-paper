# Reachable positions under the JCSA over-the-board rules

The final November 2026 experiment estimates **3.87 × 10¹⁶⁴ reachable positions with either side to move** in chu shogi. The simultaneous intervals are **[3.86576, 3.87110] × 10¹⁶⁴** for either side and **[1.93288, 1.93555] × 10¹⁶⁴** for Black to move, with at least 99.73% coverage under the sampling and proof assumptions below. Black's interval crosses the three-significant-digit boundary at 1.935 × 10¹⁶⁴. The factor of two comes from colour symmetry and is applied to the exact endpoints before rounding. [Citable code and data release](https://github.com/jh85/chushogicount-paper/releases/tag/jcsa-otb-20261122)

## Reproduce the result

From the tagged checkout, run the following command with Python 3.12 or later. It downloads the 76.2 MB evidence ZIP on first use, verifies the SHA-256 pinned in the source, checks the archived classifications, recomputes all five checkpoints including their exact integer endpoints, and prints the published CSV. The cache is under `out/jcsa-otb-20261122/`. The numerical check uses only the Python standard library.

```sh
python3 scripts/verify_jcsa.py
```

The experiment registry also exposes this verifier as `jcsa-otb-20261122` and records its output under `out/runs/`. For an offline calculation, supply the downloaded file with `--archive /path/to/jcsa-otb-20261122-evidence.zip`. To also replay all 515 included proof games, build the checker and run the same command with `--replay`. This optional check needs Git, make, a C++17 compiler and initial access to the public historical engine.

```sh
make jcsa-audit-engine
python3 scripts/verify_jcsa.py --replay
```

## State and experiment

The state consists of the board, the side to move and the effect of the preceding lion capture on legal replies. The JCSA counter-strike rule covers a protected lion on either step of a double move. Continuing states on the same board are distinct when the flag changes the legal replies. Terminal representatives on the same board and turn coincide. A flag that produces mate on an otherwise continuing board gives a distinct state. The game ends on checkmate or capture of the last royal, alongside the specified automatic endings. The count keeps left–right reflections distinct, identifies the promoted kirin with the lion, the promoted phoenix with the free king and the crown prince with the king, and excludes repetition history and server move caps.

The registered samples use three disjoint seed domains. In the table, N samples royal-present boards with the flag cleared, F samples nominal effective-flag candidates, and T samples boards on which Black has lost its last royal. A royal-present board can still be mated. Positive classifications require a legal game from the initial array. Negative classifications require a necessary-condition violation, duplicate-state determination or exhaustive predecessor proof. Unresolved draws contribute to the uncertainty interval. [Frozen settings, including exact candidate populations, domains, classifier budgets and block sizes](../experiments/jcsa-otb-20261118.json)

| Final sample | Draws | Certified reachable | Proven nonmembers | Unresolved |
|---|---:|---:|---:|---:|
| N | 320,000 | 314,808 | 5,096 | 96 |
| F | 40,000 | 35,865 | 4,127 | 8 |
| T | 24,000 | 23,970 | 25 | 5 |
| **Total** | **384,000** | **374,643** | **9,248** | **109** |

For Black to move the three contributions are `C_N × p_N + C_N × μ × p_F + C_T × p_T`. The exact candidate populations are in the settings. The static flag sample supplied 1,902,733 successes in 98,975,310 draws for μ. For N, the estimator subtracts two disjoint probabilities from one. The first is exclusion by the inexpensive screen (62,893 of four million independent draws). The second is nonmembership outside that screen, measured on **all** 320,000 full N draws. Of 5,096 proven N nonmembers, 4,964 were excluded by the matched screen. The residual lower and upper tallies are therefore 132 and 228, counting all 96 unresolved N draws at the upper end.

The registered N sample sizes were 20,000, 40,000, 80,000, 160,000 and 320,000. F, T and the static flag sample were shared across looks. The first three used one million cheap screens and the last two used four million. The one-sided Clopper–Pearson tail allocations were 0.00010 for each screen tail at each of two screen sizes, 0.00008 for each residual tail at each of five looks, and 0.00025 for each of the six shared F, T and static-flag tails. The sum is 0.00270. The stopping rule ended the experiment when both side conventions attained three digits or at the registered maximum. The run reached the maximum. An outward allowance of 336400 × 289⁶⁰ Black-to-move states covers the specified bare-king and insufficient-material discrepancies. The interval code applies this bound and its arithmetic guards before testing the rounding cells. ## Release evidence

The ZIP contains the following original production records. Its internal `SHA256SUMS` lists every member's digest. The separate release checksum covers the ZIP itself. [Evidence ZIP](https://github.com/jh85/chushogicount-paper/releases/download/jcsa-otb-20261122/jcsa-otb-20261122-evidence.zip) · [Archive checksum](https://github.com/jh85/chushogicount-paper/releases/download/jcsa-otb-20261122/SHA256SUMS)

| Files in the ZIP | Contents |
|---|---|
| `nonterm.jsonl.gz`, `flagsj.jsonl.gz`, `term.jsonl.gz` | One final classification per full draw, with seed and target board |
| `first-pass-audits.jsonl.gz`, `full-blocks.jsonl`, `screen-blocks.jsonl.gz` | First-pass checks, 192 full-block records and all 978 cheap-screen blocks |
| `example-games.jsonl.gz`, `second-pass-games.jsonl.gz`, `refutations.zip` | Three example games, all 512 additional proof games, and all 74 second-pass refutation trees with replay records |
| `freeze.json`, `completion.json`, `checkpoints/` | Production source, engine and payload hashes, the stopping record and all five original checkpoint JSON files |
| `exact-candidate-counts.txt`, `static-flags-seed171.txt`, `historical-i10-seed173.txt` | Calibration and exact-count logs, including the earlier I10 comparison |
| `registered-intervals.csv`, `registered-intervals.pdf`, `registered-intervals.svg` | The numerical table and figure for the five looks |

The numerical command checks the archived evidence and proof digests. The optional native replay independently tests moves, earlier endings, repetition and target identity for the 515 exported histories. Recomputing the intervals takes no new random draws. The full first-pass histories and working traces occupy about 80 GiB and remain in the original research run.
